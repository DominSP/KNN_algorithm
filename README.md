# KNN Algorithm

## Overview

This project presents an implementation and exploration of the K-Nearest
Neighbors (KNN) algorithm.

## Project Focus

KNN is a supervised machine-learning algorithm used for classification
and regression. It makes predictions based on the closest observations
in the feature space.

## Topics

-   K-Nearest Neighbors
-   Supervised machine learning
-   Distance-based classification
-   NumPy
-   Algorithm implementation

## Purpose

The project was created to better understand how the KNN algorithm works
and how its main concepts can be implemented programmatically.

## Repository Structure

The repository contains the source files and materials used for the KNN
project.
